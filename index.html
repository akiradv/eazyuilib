Introducing

Eazy UI

One file. One loadstring. Zero dependencies.

v0.9.15 Single file Open source MIT

Eazy UI is a Lua library that ships the entire UI stack in a single file. You get a draggable window, a sidebar with tabs, thirteen interactive elements, six themes, persistent configs, a key system, a Discord prompt and a notification system.

You load it, create a window, add your elements. That is it. The code is open source and hosted on GitHub.

lua 
local EZ = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/akiradv/eazyuilib/main/eazyui.lua"
))()

local Window = EZ:CreateWindow({
    Name = "My Hub",
    SubTitle = "by you",
    AutoLoad = true,
    Discord = {
        Enabled = true,
        Invite = "9VE4PXFDSg",
    },
})

local Tab = Window:AddTab({ Title = "Main", Icon = "home" })
Tab:AddToggle({
    Title = "My first toggle",
    Default = true,
    Callback = print
})
The instance is also exposed at getgenv().EazyUI. Loading the library again auto destroys the previous instance, so script reloads work cleanly.
Introducing

Features

What is inside the file.

6 themes

Default, Pitch, Light, Ocean, Sunset and Mono. Applied live to every open element and saved with configs.

Config system

Auto save, named configs, load, delete and reset. Orphan fields from older configs are reported instead of ignored silently.

Key system

Key screen with your own validator function, local cache with expiry and a logout call. Works with any HTTP key provider.

Notifications

Toasts in four styles with optional action buttons and open and close callbacks.

Global dropdown

One popup shared by every dropdown. Flips up near the bottom edge, clamps inside the window, closes on outside click and tab switch.

13 elements

Toggle, Slider, Dropdown, Input, Text Area, Color Picker, Keybind, Button, Progress Bar, Label, Paragraph, Section and Divider.

Discord prompt

Full screen prompt with accent stroke that copies the invite link to the clipboard instead of just opening the browser.

Auto load

Configs load automatically on script start. Disable per window with AutoLoad = false when you need manual control.

Executor safe

Filesystem, HTTP and hook calls are capability checked through EZ.Compat. Missing support disables the feature instead of crashing.

Window extras

Drag, minimize hotkey, transparency from 0 to 90 percent and loading screen.

Setup

Installation

One line.

lua 
local EZ = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/akiradv/eazyuilib/main/eazyui.lua"
))()

The call returns the library table. The same instance is available globally:

lua 
local EZ = getgenv().EazyUI
print(EZ.Version)
Read EZ.Compat before relying on configs, keys or HTTP features. See Compatibility.
Setup

Quick Start

A working hub in twenty lines.

lua 
local EZ = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/akiradv/eazyuilib/main/eazyui.lua"
))()

local Window = EZ:CreateWindow({
    Name = "Eazy Demo",
    SubTitle = "quick start",
    ConfigId = "EazyDemo",
    MinimizeKey = Enum.KeyCode.RightShift,
    AutoLoad = true,
    Discord = {
        Enabled = true,
        Invite = "9VE4PXFDSg",
    },
})

local Main = Window:AddTab({ Title = "Main", Icon = "home" })

Main:AddToggle({
    Title = "Auto Farm",
    Description = "Farms automatically",
    Default = false,
    Flag = "AutoFarm",
    Callback = function(on) print("farm:", on) end,
})

Main:AddSlider({
    Title = "Speed",
    Min = 1, Max = 100, Default = 16, Step = 1,
    Flag = "Speed",
})

local Settings = Window:AddTab({ Title = "Settings", Icon = "settings" })
Window:BuildConfigSection(Settings)

EZ:Notify({ Title = "Ready", Content = "Hub loaded.", Style = "Success" })

Parameters used

ConfigId"EazyDemo"
MinimizeKeyRightShift
AutoLoadtrue, loads saved config on start
Discordshows prompt with copy link

Run that and you have a draggable window, themed elements, auto saved configs and a complete settings tab. No boilerplate required.

UI

Configs

Files live in EazyUI_Configs as {ConfigId}_{name}.json.

Every element with a Flag is persisted automatically. A meta block also stores the theme, transparency and auto save preference.

The ready made settings tab

lua 
local Settings = Window:AddTab({ Title = "Settings", Icon = "settings" })
Window:BuildConfigSection(Settings)

Parameters used

tabthe tab object returned by AddTab

That single call builds the auto save toggle, config name input, save, load, delete and reset buttons, the saved configs dropdown, the minimize keybind, the transparency slider and the theme dropdown. Calling it twice on the same tab does nothing.

Auto load behavior

By default, CreateWindow loads the config named "default" right after the window is built. This happens after all elements are registered, so every toggle, slider and keybind restores its saved value.

To disable auto load for a specific window:

lua 
local Window = EZ:CreateWindow({
    Name = "Manual Hub",
    AutoLoad = false,
})

Parameters used

AutoLoadfalse, config must be loaded manually

Manual API

lua 
Window:SaveConfig("pvp")
Window:LoadConfig("pvp")
Window:ResetConfig("pvp")
local names = Window:ListConfigs()
Loading a config saved by an older build of your hub skips unknown fields and shows a warning notification with the count.
UI

Key System

Gate the hub behind your own validator.

lua 
local Window = EZ:CreateWindow({
    Name = "Gated Hub",
    KeySystem = {
        Enabled = true,
        Title = "Enter Key",
        Subtitle = "Get your key on the Discord",
        Note = "Keys expire after 24 hours",
        FileName = "myhub_key.json",
        validator = function(key)
            return key == "EAZY-1234"
        end,
    },
    KeyDuration = 86400,
})

Parameters used

Enabledboolean, turns the screen on
Titlestring, header text
Subtitlestring, helper line
Notestring, small note below the input
FileNamestring, where the key is cached
validatorfunction(key) returning boolean
KeyDurationnumber, cache TTL in seconds

HTTP validator

lua 
validator = function(key)
    local ok, res = pcall(function()
        return request({
            Url = "https://your.api/validate?key=" .. key,
            Method = "GET",
        })
    end)
    if not ok then return false end
    local data = game:GetService("HttpService"):JSONDecode(res.Body)
    return data.valid == true
end

Accepted keys are cached locally until expiry. A wrong key keeps the screen open with an error line. Cancelling makes CreateWindow return nil, so the rest of your script never runs.

lua 
EZ:Logout()
UI

Discord Prompt

Full screen prompt that copies the invite link to the clipboard.

lua 
local Window = EZ:CreateWindow({
    Name = "Social Hub",
    Discord = {
        Enabled = true,
        Invite = "9VE4PXFDSg",
    },
})

Parameters used

Enabledboolean, turns the screen on
Invitestring, code only, no full URL

The prompt shows before the main window opens. It has an accent stroke, a big "D" icon, the invite code displayed in mono font and two buttons: Copy Link and Skip.

Copy Link uses setclipboard or toclipboard to put the full invite URL (https://discord.gg/...) into the user clipboard. The button text flips to "Copied!" for a second to confirm. If the executor has no clipboard function, the URL is shown directly on the button so the user can copy it manually.

Skip just closes the prompt and lets the window open. Every click advances the prompt, so there is no hanging state.

The user still needs to paste the link in a browser or Discord. The prompt does not auto open the invite.

Compatibility

The library never assumes the executor can do something.

lua 
if not EZ.Compat.files then
    warn("configs disabled: no file support")
end

if not EZ.Compat.http then
    warn("key system disabled: no HTTP support")
end
FlagUsed by
filesConfigs, key cache
foldersCreating the config folder
listWindow:ListConfigs()
huiPreferred GUI parent
protectGUI protection from detection
httpHTTP validators and invite opener
hooksMetamethod hooks, when your hub needs them

The Discord prompt also checks for setclipboard or toclipboard. If neither exists, the button falls back to showing the URL as text.

Changelog

Release history.

v0.9.15

  • Discord prompt redesigned: accent stroke, big icon, copy link button instead of open in browser.
  • New AutoLoad option on CreateWindow, defaults to true.
  • Removed RememberJoins from the Discord prompt.
  • example.lua moved to the repository root; Showcase loadstring and live check now point to it.

v0.9.14

  • Strokes on text objects outline the box, never the glyphs.
  • Focus aware stroke repaint: theme changes no longer reset the accent border while typing.
  • Dropdown popup repaint deduplicated.
  • Transparency range extended to 90 percent, slider and clamp aligned.
  • Auto save preference persisted in config meta.
  • Inputs and text areas use mono font, slider and progress values use the accent color.
  • Dropdown trigger resized to match inputs.
  • Config listing hardened for Windows style paths.

v0.9.12 to v0.9.13

  • Default theme became an independent table, switching back now applies for real.
  • Global dropdown popup manager, idempotent BuildConfigSection, orphan field warnings, color picker debounce, destroy cleanup.

v0.9.5 to v0.9.11

  • Dropdown manager rewrite, stroke and corner fixes, sidebar layout rebuild, loading screen redesign.
