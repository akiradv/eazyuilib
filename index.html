Introducing

Eazy UI

One file. One loadstring. Zero dependencies.

v0.9.55 Single file Open source MIT

Eazy UI is a single-file Roblox interface library with responsive windows, tabs and sections, controls, search, localization, themes, notifications and optional persistence. The library source is eazyui.lua.

Create a window, add tabs, then add elements. See Features, Quick Start and the full element overview.

lua 
local EZ = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/akiradv/eazyuilib/main/eazyui.lua"
))()

local Window = EZ:CreateWindow({ Name = "My Hub" })
if not Window then return end

local Main = Window:AddTab({ Title = "Main", Icon = "home" })
Main:AddToggle({
    Title = "Enabled",
    Flag = "Enabled",
    Default = false,
    Callback = function(value) print("Enabled:", value) end,
})
For the loadstring to use this version, eazyui.lua must be updated in the repository. Optional filesystem, custom-asset and request features depend on the environment. See Compatibility.
Introducing

Features

Everything included in v0.9.55.

Responsive desktop & mobile

Draggable, resizable window with viewport-aware layout, a compact sidebar and a draggable reopen button on touch devices.

Search in the active tab

Filters controls and sections by original and translated titles or descriptions; clearing the search restores the layout.

Languages & dictionaries

English, Brazilian Portuguese and Spanish, live switching, common translations and custom text tables for your hub.

Built-in & custom themes

Eleven palettes, live accent colors and user-registered themes with inheritance.

Configs & autosave

Unique flags, named configs, optional autoload, debounced saves and metadata for appearance and language.

Multiple instances

Opt in to keep previous executions, with separate config IDs and mobile buttons. Default reload behavior closes the previous execution.

Controls & callbacks

Fifteen Add methods, including toggles, buttons, sliders, range sliders, dropdowns, color pickers, inputs and keybinds.

Searchable & multi-select dropdowns

Filter long lists, select one or several values, replace options at runtime and keep raw values in callbacks.

Notifications

Four styles and positions, queued messages, action buttons, input prompts and open/close callbacks.

Minimize & transparency

Fade or shrink animation, configurable shortcut, transparency strength and a collapsible sidebar.

Key & Discord prompts

Optional key screen with your validator and cache; optional Discord invite prompt and loading screen.

WindUI icons & logo

Named Lucide/WindUI Roblox assets, custom asset IDs, and a configurable PNG or Roblox logo asset.

Lifecycle & safe callbacks

Destroy the library when finished; interface callbacks are protected so an error is reported without crashing the interface.

Interaction details

Dropdowns close on Escape or outside click, sliders support fine adjustment, and keybinds support Ctrl/Shift/Alt combinations.

Setup

Installation

Load the current library from one file.

The public loadstring points to eazyui.lua. Use it only in an environment that supports game:HttpGet and loadstring:

lua 
local EZ = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/akiradv/eazyuilib/main/eazyui.lua"
))()

print(EZ.Version)

Alternatively, copy the complete eazyui.lua source into your project and adapt the loading mechanism to your environment. It uses Roblox services; file and custom-asset features require additional APIs.

The URL loads whatever is currently published on the repository’s main branch. Upload the updated library before expecting the new API remotely.
Setup

Quick Start

Create your first window and settings tab.

lua 
local EZ = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/akiradv/eazyuilib/main/eazyui.lua"
))()

local Window = EZ:CreateWindow({
    Name = "Example Hub",
    SubTitle = "My first interface",
    Theme = "Default",
    Language = "en",
    ConfigId = "ExampleHub",
    MinimizeKey = Enum.KeyCode.RightControl,
})
if not Window then return end

local Main = Window:AddTab({ Title = "Main", Icon = "home" })
Main:AddSection({ Title = "General" })
Main:AddToggle({
    Title = "Enabled",
    Default = false,
    Flag = "Enabled",
    Callback = function(value) print("Enabled:", value) end,
})
Main:AddButton({
    Title = "Say hello",
    ButtonText = "Run",
    Callback = function() print("Hello!") end,
})

local Settings = Window:AddTab({ Title = "Settings", Icon = "settings" })
Window:BuildConfigSection(Settings)
EZ:Notify({ Title = "Ready", Content = "The interface has loaded.", Style = "Success" })

Flag names must be unique in a window. The settings tab provides config, language, theme, minimize and transparency controls. Depending on the saved config, autoload can override some initial appearance options.

Next: Window options · Languages · Configs.

UI

Tab Search

Find a control without leaving the active tab.

The search field is enabled by default and filters the active tab. It checks section titles, row titles and descriptions against both source text and the current translation. Matching is case-insensitive and folds common Portuguese and Spanish accents.

A section title match includes its eligible children. Clearing the query restores the earlier visibility and section layout. Switching tabs applies the same query to the newly active tab.

lua 
Window:SetSearch("speed")
print(Window:GetSearch())
Window:SetSearch("")

Disable the field

lua 
local Window = EZ:CreateWindow({ Name = "My Hub", SearchEnabled = false })
-- Search = false is also accepted.

Window:SetSearch can still filter programmatically when the field is hidden. This search is separate from a dropdown’s Searchable = true, which filters that dropdown’s options.

UI

Appearance & Mobile

Sidebar, minimize behavior, transparency and the logo.

Minimizing

fade hides the window with a fade; shrink reduces it to its title bar. Use the title-bar button or keyboard shortcut. On touch devices a draggable floating button restores the minimized window.

lua 
Window:SetMinimizeMode("shrink")
Window:SetMinimized(true)
Window:SetMinimized(false)
Window:SetMinimizeKey(Enum.KeyCode.K, "Ctrl+")
Window:SetSidebarCollapsed(true)
Window:SetSidebarCollapsed(false)

Transparency

Transparency is 0–0.9; TransparencyStrength scales the transparency of the main surfaces from 0 (opaque) to 1 (full configured strength), default 0.4. For example:

lua 
local Window = EZ:CreateWindow({
    Name = "My Hub",
    Transparency = 0.5,
    TransparencyStrength = 0.4,
})
if not Window then return end
Window:SetTransparency(0.25)
True transparency reveals the game and characters behind the window; it is not a blur or a solid-color background. Use Transparency = 0 or TransparencyStrength = 0 for opaque main surfaces.

Sidebar and mobile

The sidebar can expand or collapse; its widths and initial state are configurable. Compact layout can automatically collapse it, and selecting a tab on a compact screen closes the expanded sidebar. The window, dropdown and floating button adapt to viewport changes; exact rendering depends on the Roblox client and device.

Logo

The default logo PNG is embedded in the library. When supported, it is converted into a local custom asset; otherwise a fallback mark is shown. LogoAsset accepts a Roblox asset string or numeric ID directly. A custom LogoUrl must point to a PNG and needs HTTP, file and custom-asset support. LoadLogo = false skips automatic loading.

lua 
local Window = EZ:CreateWindow({
    Name = "My Hub",
    LogoAsset = "rbxassetid://1234567890",
    -- Or: LogoUrl = "https://example.com/logo.png",
})

Register a custom theme

Register the theme before applying it or before an autoloaded config needs it. A custom theme inherits missing fields from the base theme, which defaults to Default. Custom themes are in memory and must be registered again on every execution.

lua 
local ok, err = EZ:RegisterTheme("MidnightGreen", {
    Background = Color3.fromRGB(10, 18, 15),
    Card = Color3.fromRGB(20, 34, 28),
    Accent = Color3.fromRGB(80, 210, 150),
    Radius = 8,
    RadiusWindow = 12,
}, "Default")
if not ok then warn(err) end
EZ:SetTheme("MidnightGreen")
print(EZ:GetTheme())
for _, name in ipairs(EZ:ListThemes()) do print(name) end

Valid color fields: Background, Card, CardHover, Border, BorderHover, TabActive, Text, TextDim, Accent, AccentDim, Success, Warning, Error and Info. Radius and RadiusWindow are numbers between 0 and 100. An omitted AccentDim is derived from a supplied accent.

Built-in theme names and aliases cannot be overwritten. SetAccent changes the active palette in memory; a config stores the theme name, not custom theme definitions or arbitrary accent colors.
UI

Languages & Translations

Three built-in languages and dictionaries for your own hub.

Supported languages are en, pt-BR and es; aliases include en-US, pt, es-ES and es-MX. Changing the language refreshes the library UI and registered text bindings without rebuilding the window.

lua 
EZ:SetLanguage("pt-BR")
print(EZ:GetLanguage())
for _, language in ipairs(EZ:ListLanguages()) do print(language) end
EZ:SetLanguage("es")

Translate your own text

Built-in interface text and some common labels already have translations. Register a dictionary for every custom title, description, placeholder or notification that needs translation. Literal-text keys match the complete original string.

lua 
EZ:RegisterTranslations({
    en = {
        launch_title = "Launch",
        launch_desc = "Start the feature",
    },
    ["pt-BR"] = {
        ["Farming"] = "Coleta",
        launch_title = "Iniciar",
        launch_desc = "Iniciar o recurso",
    },
    es = {
        ["Farming"] = "Recolección",
        launch_title = "Iniciar",
        launch_desc = "Iniciar la función",
    },
})

local Window = EZ:CreateWindow({ Name = "My Hub", Language = "pt-BR", AutoLoad = false })
if not Window then return end
local Main = Window:AddTab({ Title = "Farming", Icon = "home" })
Main:AddButton({
    Title = "loc:launch_title",
    Description = "loc:launch_desc",
    Callback = function() print("Started") end,
})
print(EZ:Translate("loc:launch_title"))

You can also register one language with EZ:RegisterTranslations("pt-BR", { ["Original"] = "Tradução" }), or pass the same language-keyed table in CreateWindow.Translations. Registration returns true or false, error. Only the three supported language codes are accepted.

For plain text with no match, the original stays visible. For loc:key, Eazy UI falls back to the English entry, then [key]. Dictionaries are in memory and must be registered again on every execution; a config stores the language choice, not the dictionaries.

This is dictionary-based localization, not automatic machine translation. Arbitrary script text will not be translated unless your dictionary supplies it.

Values and editable text

Dropdown option labels can be translated, but callbacks and saved values use the original values. Pass TranslateValues = false for identifiers or user data. Input and text-area contents are not automatically translated; their placeholders can be.

lua 
Main:AddDropdown({
    Title = "Region",
    Values = { "br-01", "us-02" },
    TranslateValues = false,
    Callback = function(rawValue) print(rawValue) end,
})

Override built-in labels

EZ:SetLocale(key, value) or EZ:SetLocale({ key = value }) customizes internal interface labels for the current locale. Calling SetLanguage resets built-in labels to that language; use RegisterTranslations for your own text.

UI

Multiple Instances

Keep separate hubs open when you explicitly opt in.

By default, the first CreateWindow call in a fresh library execution destroys previous registered executions. Set AllowMultiple = true on that first call if the new execution must coexist with them.

lua 
local source = "https://raw.githubusercontent.com/akiradv/eazyuilib/main/eazyui.lua"

local EZ1 = loadstring(game:HttpGet(source))()
local Window1 = EZ1:CreateWindow({
    Name = "First Hub",
    ConfigId = "FirstHub",
    MinimizeKey = Enum.KeyCode.RightControl,
})

local EZ2 = loadstring(game:HttpGet(source))()
local Window2 = EZ2:CreateWindow({
    Name = "Second Hub",
    ConfigId = "SecondHub",
    MinimizeKey = Enum.KeyCode.RightShift,
    AllowMultiple = true,
})

-- Close just the second library execution:
-- EZ2:Destroy()
  • Use a stable, distinct ConfigId for each hub. Duplicate IDs can overwrite the same config files.
  • Use distinct minimize shortcuts; the same shortcut can toggle several windows.
  • Each execution gets its own library state and its own mobile reopen button. Registry access uses a protected shared environment when available.
  • If no shared environment is available, coexistence and cleanup across separate executions cannot be coordinated reliably; use unique IDs and shortcuts.
The instance registry is exposed as getgenv().EazyUIInstances when getgenv() is available; EazyUI points to the latest registered instance. The library also attempts protected fallback environments.
UI

Configs

Named saves, autoload and persistent flagged controls.

Flagged controls can be saved to EazyUI_Configs/{ConfigId}/{name}.json. The autoload selection is stored separately in the same directory. Config IDs are sanitized for paths. Legacy flat files can be read and listed; legacy files must be removed manually rather than deleted through the API.

Unique flags

Use a stable, nonempty, unique string Flag for each persisted toggle, slider, range, dropdown, input, text area, color picker or keybind. _meta is reserved; avoid _minimize_key, which is used by the settings section. Unflagged controls are not persisted.

lua 
Main:AddToggle({
    Title = "Auto collect",
    Flag = "AutoCollect",
    Default = false,
    Callback = function(value) print(value) end,
})
local Settings = Window:AddTab({ Title = "Settings", Icon = "settings" })
Window:BuildConfigSection(Settings)

The ready-made settings section includes save/load/delete/reset, autoload selection, autosave, minimize shortcut and mode, transparency, theme and language controls. Calling it again on the same tab does nothing.

Saving and loading

Autosave is enabled by default and batches writes with a one-second delay. Autoload is enabled by default; when saved values are available before controls are registered, flagged controls receive their values as they are added. Applying saved values invokes their callbacks. Use AutoLoad = false for manual loading.

lua 
local ok, err = Window:SaveConfig("pvp")
if not ok then warn(err) end

ok, err = Window:LoadConfig("pvp")
if not ok then warn(err) end

local names = Window:ListConfigs()
ok, err = Window:ResetConfig("pvp")
ok, err = Window:DeleteConfig("pvp")
ok, err = Window:FlushSaves()

Manual save, load, reset, delete and flush return success or an error. ListConfigs returns an array. ResetConfig restores defaults for registered flagged controls and writes the result. Loading flushes pending saves first.

Config names must be nonempty, at most 80 characters, and cannot be _autoload, contain .., path separators, control characters or : * ? " < > |. Saved metadata includes the theme name, language, transparency, autosave preference, minimize mode, sidebar state and window size. Custom themes and translation tables must be registered again when the script starts.

Filesystem APIs differ by environment. Check ok, err instead of assuming saving or deletion succeeded. Explicitly loading a config before all controls are registered can report unregistered fields; their data is preserved.
UI

Key System

Optional prompt with your own validator.

Provide a validator(key) function that returns exactly true for a valid key. Without a validator, keys do not pass. KeyDuration is a top-level window option, in seconds.

lua 
local Window = EZ:CreateWindow({
    Name = "Gated Hub",
    ConfigId = "GatedHub",
    KeyDuration = 86400,
    KeySystem = {
        Enabled = true,
        Title = "Enter Key",
        Subtitle = "Get your key from the provider",
        Note = "Example only",
        validator = function(key)
            return key == "EXAMPLE-KEY"
        end,
    },
})
if not Window then
    warn("Access cancelled or denied")
    return
end

A successful key is cached in eazyui_key_{ConfigId}.json (with a sanitized ID) when filesystem support exists, then revalidated on later launches. The interactive validator waits up to five seconds per attempt; the prompt itself closes after approximately 30 seconds. Cancelling or failing to finish returns nil from CreateWindow; your script must check it and return explicitly.

lua 
EZ:Logout()
This is a client-side interface and local cache, not strong security. A key hard-coded in a client script can be read or bypassed. Protect sensitive operations on a trusted server; never place secrets in the client.
UI

Discord Prompt

Full screen prompt that copies the invite link to the clipboard.

lua 
local Window = EZ:CreateWindow({
    Name = "Social Hub",
    Discord = {
        Enabled = true,
        Invite = "9VE4PXFDSg",
    },
})

Parameters used

Enabledboolean, turns the screen on
Invitestring, code only, no full URL

The prompt shows before the main window opens. It has an accent stroke, a big "D" icon, the invite code displayed in mono font and two buttons: Copy Link and Skip.

Copy Link uses setclipboard or toclipboard to put the full invite URL (https://discord.gg/...) into the user clipboard. A successful copy closes the prompt. If clipboard access is missing, the URL is shown on the button temporarily and the prompt remains open.

Skip closes the prompt and lets the window open. The prompt also closes after approximately 30 seconds.

The user still needs to paste the link in a browser or Discord. The prompt does not auto open the invite.

Notifications

Toasts, action buttons and input prompts.

Notifications queue and reflow to fit the viewport. They support Info, Success, Warning and Error styles; choose the screen corner with CreateWindow.NotifyPosition.

lua 
EZ:Notify({
    Title = "Saved",
    Content = "Your configuration was saved.",
    Style = "Success",
    Duration = 4,
    OnOpen = function() print("opened") end,
    OnClose = function(reason) print("closed:", reason) end,
})

EZ:Notify({
    Title = "Choose",
    Content = "Continue?",
    Duration = 0,
    Buttons = {
        { Title = "Yes", Callback = function() print("yes") end },
        { Title = "No", Callback = function() print("no") end },
    },
})
Option Default Description
Title "Eazy UI" Notification heading.
Content "" Wrapped message; long content can scroll.
Style "Info" Info, Success, Warning or Error.
Duration automatic Seconds; 0 leaves the toast open until an action or close.
Buttons {} Array of { Title, Callback }; actions close the toast.
OnOpen nil Called when the toast is shown.
OnClose nil Called with a close reason.
Input false Use true to show an input instead of action buttons.
InputPlaceholder localized Placeholder for the input.
InputCallback nil Called with the entered string.
CloseOnInput true Set false to keep the input toast open after submission.

Input notification

lua 
EZ:Notify({
    Title = "Player name",
    Content = "Enter a name:",
    Input = true,
    InputPlaceholder = "Name",
    InputCallback = function(text) print("Entered:", text) end,
    CloseOnInput = true,
})

Input notifications do not auto-dismiss on a timer and do not display Buttons. With automatic duration, short messages use an estimated 3–20 seconds; long scrollable messages stay open. Close reasons include Close, Input, Action, Timeout, Overflow and Destroy.

Elements

Element Overview

All constructors, values and methods in one place.

Every constructor below is called on a tab returned by Window:AddTab. Multi = true is a mode of AddDropdown, not a separate constructor.

Constructor Element Returned methods Behavior
Tab:AddSection(...) Section Set(text) Collapsible group; following elements belong to this section until the next one.
Tab:AddBanner(...) Banner SetTitle(text), SetSubtitle(text) Decorative card with optional image, title and subtitle.
Tab:AddDivider(...) Divider Set(bool) Horizontal separator; Set controls visibility.
Tab:AddParagraph(...) Paragraph Set(text) Wrapped content card. Provide Content at creation to update it later.
Tab:AddLabel(...) Label Set(text) Simple wrapped text.
Tab:AddToggle(...) Toggle Set(bool, silent) Boolean value, callback and optional right/middle click.
Tab:AddButton(...) Button Fire(), SetTitle(text) Action button; SetTitle changes the button label.
Tab:AddSlider(...) Slider Set(number, silent) Single numeric value, snapped to Min/Max/Step.
Tab:AddRangeSlider(...) Range Slider Set({low, high}, silent) Two numeric handles; callback receives an array.
Tab:AddDropdown(...) Dropdown / Multi-Select Set(value, silent), SetValues(array), getValues() Single choice or Multi = true; optional search and localized labels.
Tab:AddInput(...) Input Set(text, silent) Single-line input, commits on focus loss.
Tab:AddTextArea(...) Text Area Set(text, silent) Multiline input, commits on focus loss.
Tab:AddProgressBar(...) Progress Bar Set(number) Display-only percentage, clamped to 0–100 when set.
Tab:AddColorPicker(...) Color Picker Set(Color3, silent), Get() HSV picker and hex input.
Tab:AddKeybind(...) Keybind Set(KeyCode, silent, modifiers) OnTriggered or Callback receives KeyCode and modifiers; OnChanged receives changes.

Shared conventions

  • Most controls accept a table with Title, optional Description, Default, Flag and Callback; check each element page for the fields it actually supports.
  • Most interactive controls store their current value in Value; range sliders instead expose MinValue and MaxValue. The color picker additionally has Get().
  • A supported Set(value, true) updates the UI silently: it suppresses the callback and automatic save scheduling for that operation. A later manual save can still include the current value.
  • Description on slider, range slider, text area, progress bar and color picker contributes to search but is not shown as a second line in those controls.
  • CreateX aliases the corresponding AddX method, for example Tab:CreateToggle(...).

For paragraph, toggle, button, slider, range slider, dropdown, input, text area, progress bar, color picker and keybind, a title string plus an options table is also accepted:

lua 
local slider = Main:AddSlider("Walk Speed", {
    Min = 16,
    Max = 100,
    Default = 16,
    Flag = "WalkSpeed",
    Callback = function(value) print(value) end,
})

AddSection and AddBanner take a table; AddLabel takes a string; AddDivider takes no options. Give persisted controls unique flags: see Configs.

Range Slider

Dual handle slider for min/max ranges. Both knobs are draggable and the callback receives the pair as an array.

Option Type Default Description

Step number 1 Snap step.

    Min = 0, Max = 100, Default = { 20, 80 }, Step = 5,

Parameters used

Title"Damage Range"
Min / Max0 / 100
Default{ 20, 80 }

The lower knob cannot pass the higher one, and vice versa. Both values are persisted as a JSON array in the config file.

Multi-Select

Dropdown that lets the user pick several values at once. The trigger shows the selected labels separated by commas.

Option Type Default Description
Title string "Dropdown" Row title.
Description string "" Optional second line.
Values table {} Array of options.
Default table {} Initial selection, array of values.
Multi boolean false Set true to enable multi-select.
Searchable boolean false Adds a filter input inside the popup.
Flag string nil Enables config saving.
Callback function(array) nil Fires on every pick toggle.
lua 
local multi = Tab:AddDropdown({

    Description = "Pick who to highlight",

    Flag = "ESPTargets",

Parameters used

Multitrue, enables multi-select mode
Valuesarray of options
Defaultinitial selection array

The popup stays open after each pick so the user can select several options without reopening it. Click outside or press Escape to close.

Selected values in callbacks and configs are the original values, not their translated labels. Use TranslateValues = false to display the originals too.

Color Picker

Swatch that expands into a full panel: saturation and value canvas, dedicated hue bar, live color preview and editable hex input. Drag callbacks are debounced at approximately 60ms.

lua 
local picker = Tab:AddColorPicker({
    Title = "ESP Color",
    Default = Color3.fromRGB(16, 185, 129),
    Flag = "ESPColor",
    Callback = function(c3) print(c3) end,
})
picker:Set(Color3.fromRGB(255, 0, 0))

Parameters used

Title"ESP Color"
DefaultColor3, defaults to white
Flag"ESPColor"
Set(Color3, silent)programmatic color

The expanded panel is built from three parts: a large canvas where the X axis controls saturation and the Y axis controls value, a vertical hue bar on the right and a live preview strip at the bottom showing the current color. The #RRGGBB input sits beside the preview below the canvas. Press Enter to parse and apply the hex value. Invalid input is ignored.

Read the current value with picker:Get() or picker.Value; use picker:Set(color, true) for a silent update. Description is searchable but not displayed.

Element

Keybind

Click, press a key, done. Escape cancels. The bind fires globally, ignored while typing. Modifier keys (Ctrl, Shift, Alt) are captured together with the main key.

lua 
local bind = Tab:AddKeybind({
    Title = "Toggle Hub",
    Default = Enum.KeyCode.RightControl,
    Flag = "HubBind",
    Callback = function(key) print("pressed", key.Name) end,
})
bind:Set(Enum.KeyCode.F1)

Parameters used

Title"Toggle Hub"
DefaultEnum.KeyCode, defaults to RightShift
Flag"HubBind"
Set(KeyCode, silent, modifiers)programmatic bind

Hold Ctrl, Shift or Alt while pressing the key and the binding becomes a combo like Ctrl+K. The callback only fires when the same modifiers are held at trigger time.

OnTriggered(key, modifiers) takes priority over Callback(key, modifiers) when both are provided. OnChanged(key, modifiers) fires when the binding changes. DefaultMods and the third argument to Set use strings such as "Ctrl+" or "Ctrl+Shift+". Modifier order is Ctrl, Shift, Alt.

Compatibility

Capabilities and their actual limits.

EZ.Compat reports whether certain global functions are present. A flag is a hint, not a guarantee that an operation will succeed: check return values and errors for filesystem or network operations.

lua 
if not EZ.Compat.files or not EZ.Compat.folders then
    warn("Saving configs may be unavailable")
end
if not EZ.Compat.http then
    print("The request function is not present")
end
if not EZ.Compat.instances then
    warn("No shared registry for multiple executions")
end
Flag What it checks
files writefile, readfile and isfile are present.
folders makefolder and isfolder are present.
list listfiles is present.
hui gethui is present.
protect protectgui is present; no promise of invisibility or security.
http request is present. Local key validators do not need HTTP.
hooks hookmetamethod is present.
instances A writable shared environment for the instance registry was found.

Additional APIs are checked where needed: config deletion needs delfile; a cached PNG logo needs file access and getcustomasset or getsynasset; the Discord copy button uses setclipboard or toclipboard. Without clipboard support the invite is displayed as text.
